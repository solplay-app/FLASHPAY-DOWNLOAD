Télécharger FlashPay

Téléchargement lancé. Quand il est terminé, ouvrez le fichier depuis la notification de votre téléphone (ou le dossier « Téléchargements »).

Vous êtes sur iPhone : la version iOS n’est pas encore disponible. Ouvrez cette page depuis un téléphone Android pour installer FlashPay.

Vous êtes sur ordinateur : scannez le QR code avec votre téléphone Android pour ouvrir cette page dessus.

Comment l’installer

  1. Appuyez sur Télécharger FlashPay et attendez la fin du téléchargement.
  2. Ouvrez le fichier téléchargé. Si Android le demande, autorisez l’installation depuis votre navigateur (« Installer des applications inconnues »).
  3. Appuyez sur Installer, puis ouvrez FlashPay.
Pourquoi Android affiche-t-il un avertissement ?

FlashPay n’est pas encore sur Google Play, donc Android signale une installation « hors boutique ». C’est normal. Téléchargez toujours l’application depuis ce site officiel uniquement, et ne la récupérez jamais via un lien reçu d’un inconnu.
